ПРОТОТИП 2D ШУТЕРА
C++ / ФРЕЙМВОРК SFML

===============================================================

Обзор проекта: Компактный прототип двухмерного шутера, разработанный на C++ с использованием библиотеки SFML. Включает систему персонажа, механику стрельбы, систему снарядов, карту на основе тайлов и базовую игровую архитектуру.

СИСТЕМА ГЕРОЯ

Класс: Hero (наследуется от Entity)
Физика: Передвижение, прыжки и симуляция гравитации.
Анимация: Покадровая анимация спрайтов в зависимости от состояния.
Управление: Обработка направления взгляда (влево / вправо).
Отладка: Визуализация хитбокса (Collision Box) для настройки столкновений.
Интерфейс: Отображение текущего уровня здоровья на экране.

ОРУЖИЕ И ПУЛИ

Оружие:
Абстрактный класс Weapons: задает общую логику для всех типов пушек.
Виртуальный метод shoot(...): позволяет реализовать разное поведение стрельбы.
Реализация: Класс WeaponsKalashnikov (наследник с конкретными характеристиками).
Пули:
Класс Bullet: расчет движения на высокой скорости с использованием deltaTime.
Оптимизация: Проверка выхода за границы экрана для удаления лишних объектов.
Коллизии: Точный расчет зоны попадания через FloatRect.
Векторная физика: Скорость и направление задаются вектором движения.

СИСТЕМА КАРТЫ

Хранение: Уровень задан в виде ASCII-символов в массиве arr[].
Визуализация: Автоматическая конвертация символов в объекты спрайтов (тайлы).
Столкновения: Список collisionTiles для обработки препятствий.
Структура: Простая и понятная архитектура карты, удобная для расширения.
